# SC/ST (Prevention of Atrocities) Act — National Dashboard

An interactive React dashboard visualizing state-wise case registration, chargesheet rates,
conviction rates, and procedural outcomes under the SC/ST (Prevention of Atrocities) Act,
benchmarked against NCRB "Crime in India" reporting and Ministry of Social Justice &
Empowerment statistics.

## Stack

- React + Vite
- Tailwind CSS v4
- Recharts
- lucide-react

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Data sources and legal context (Section 3 of the PoA Act) are cited directly in the
dashboard's footnote section.
